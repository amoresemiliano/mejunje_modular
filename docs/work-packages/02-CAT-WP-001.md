---

## 4. Key Architectural Decisions

1. **Current Commercial Pricing Authority**: `02-CAT` owns current active retail prices. Order historical snapshots are deferred to `11-PED`. Money amounts use `numeric(12, 2)` to prevent floating-point loss.
2. **Deny-by-Default RLS**: Public visitors (`anon`) and registered customers (`authenticated` non-staff) can SELECT published catalog data only. All administrative mutations (INSERT, UPDATE, DELETE) require active admin credentials (`public.is_admin()`).
3. **Public Storage Assets**: Media metadata is stored in `public.catalog_media`, with binaries stored in the public `catalog-media` Supabase bucket.
4. **Olfactory Pyramid Isolation**: Olfactory notes are stored as commercial arrays (`top_notes`, `heart_notes`, `base_notes`), completely decoupled from secret formulas in `05-LAB`.
