## 4. Key Architectural Decisions & NEXUS Corrections

1. **Catalog Media Target & Strict Resolution**:
   - `catalog_media` enforces target constraint `check (num_nonnulls(product_id, variant_id) = 1)`.
   - `catalog_media_select_policy` strictly resolves `product.status = 'published'` for product media, or `variant.is_active = true AND product.status = 'published'` for variant media. Eliminates unverified public shortcuts (`product_id IS NULL`).

2. **Public Storage Bucket Strategy (Strategy A)**:
   - Storage bucket `catalog-media` is public and holds commercial media assets.
   - Database `catalog_media` RLS policies restrict metadata SQL queries, but do not physically mask binary storage objects in a public bucket.

3. **Automatic `updated_at` Triggers**:
   - Reuses Core helper function `public.set_updated_at()` via `BEFORE UPDATE` triggers on all 6 tables containing `updated_at`.

4. **Currency Format Integrity & Price Semantics**:
   - Enforces uppercase 3-letter currency format via `check (currency ~ '^[A-Z]{3}$')`.
   - `unique (variant_id, currency)` constraint enforces single-price row authority per variant/currency combination (both active and inactive). Historical order price snapshots belong to `11-PED`.

5. **Explicit PostgreSQL Table Privileges**:
   - `anon` granted `SELECT` only; write operations explicitly revoked.
   - `authenticated` granted table-level `SELECT, INSERT, UPDATE, DELETE` to permit mutation attempts; RLS policies strictly limit mutation execution to `public.is_admin()`.
